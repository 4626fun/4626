// How it works

Three steps. One vault. Shared yield.

The ERC-4626 standard turns any strategy into a tokenized share. Creators run the strategy, depositors hold the shares, the chain settles the math.

  1. 01

    Creator deploys a vault

    Pick a strategy, set fees, mint a tokenized 4626 vault on Base in one transaction. Your vault, your rules, your on-chain reputation.

  2. 02

    Community deposits in

    Fans, friends, and strangers deposit USDC, ETH or any supported asset and receive 4626 shares. One vault, one position, one shared engine.

  3. 03

    Yield flows back, together

    Strategy gains accrue to the share price. Depositors redeem any time, creators earn a transparent performance fee. Everyone settles on-chain.

// Features

A protocol for shared upside.

Built on the ERC-4626 tokenized vault standard. Every action is composable, inspectable, and replicable on-chain — by design.

ERC-4626 native

Every vault is a tokenized share. Composable across DeFi by default — wallets, aggregators, and analytics all speak the same standard.

Async deposits & withdrawals

Strategies can settle on their own cadence using EIP-7540 async flows. No forced liquidity. No mismatched timing.

Verifiable on-chain

Holdings, P&L, fees, depositors — every byte readable on Base. No black boxes. The chain is the audit log.

Creator performance fees

Set a high-water-mark performance fee in basis points. Creators only earn when depositors earn. Aligned by code.

Social leaderboard

Vaults ranked by APY, TVL, and follow count. Discover strategists by track record, not promises.

Base-native & gas-light

Deployed on Base for cheap, fast settlement. Account-abstraction friendly so depositors can join in one click.
