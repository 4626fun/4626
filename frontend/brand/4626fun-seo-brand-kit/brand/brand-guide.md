## Core logo system

- **Primary horizontal lockup:** `logo/lockups/4626fun-horizontal-lockup-light-2048x1152.png`

## Recommended usage

Use the horizontal lockup for website headers, Open Graph cards, pitch decks, and wide ads. Use the stacked lockup for app splash screens, vertical social posts, and square placements. Use the icon-only mark at small sizes, favicons, PWA icons, and profile avatars.

## Technical note

The icon-only asset uses true alpha transparency. The transparent lockups are clean web-ready composites made from the true-alpha icon and transparent wordmark extraction. The SVG files are high-detail SVG wrappers that embed transparent PNGs to preserve metallic reflections, gradients, and glow more accurately than a lossy auto-trace.
