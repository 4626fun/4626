what does flip mean

## Assistant

`flip` means the user crossed through zero and reversed direction in a single fill.

Example:

- Before fill: `+0.25` (long)
- Fill side/size: `sell 1.0` (short delta)
- After fill: `-0.75` (short)

That is not just reducing or closing — it **closes the existing side and opens the opposite side** in one move, so we classify it as `flip`.

How it differs:

- `add`: same direction, bigger position
- `reduce`: same direction, smaller position
- `close`: goes to (near) zero
- `flip`: changes sign (long -> short or short -> long)
