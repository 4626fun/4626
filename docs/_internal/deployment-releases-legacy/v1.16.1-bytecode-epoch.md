## On-chain operator steps

### 1. Re-seed bytecode store (idempotent)

```bash
export UNIVERSAL_BYTECODE_STORE=0x7D1029a832E2BEd2C961bC912b623b763862Ad3C
export BASE_RPC_URL=<paid Base RPC>
export PRIVATE_KEY=<store owner signer>

./script/seed-v1161-bytecode-store.sh
```

Batched alternative (same env vars):

```bash
SEED_OFFSET=0  SEED_LIMIT=12 ./script/seed-v1161-bytecode-store.sh
SEED_OFFSET=12 SEED_LIMIT=12 ./script/seed-v1161-bytecode-store.sh
SEED_OFFSET=24 SEED_LIMIT=12 ./script/seed-v1161-bytecode-store.sh
```

### 2. Replace batcher shell (required — live shell lacks `shareMeshHelper()`)

Live shell `0x17163e67dED6B45bd2A7E6a509A32fB7b0cB6D33` reverts on `shareMeshHelper()`. Helper hot-swap alone cannot work; deploy a fresh CREATE2 shell bound to new helpers:

```bash
export OLD_DEPLOYMENT_BATCHER=0x17163e67dED6B45bd2A7E6a509A32fB7b0cB6D33
export SHELL_UPGRADE_EPOCH_TAG=v1.16.1-share-mesh
./script/upgrade-batcher-shell-share-mesh.sh
```

The script:
- CREATE2-deploys a new shell + phase1/2/3/share-mesh helpers (reuses store, create2 deployer, vault modules, utils helper)
- Executes `wireDeploymentHelpers` + `setPhase1Module` via protocol treasury Safe
- Copies Solana / OVault runtime config from the old shell
- Authorizes the new shell on `Registry4626` + `UniversalCreate2DeployerFromStore`

After broadcast, update `frontend/src/config/contracts.defaults.ts`, `docs/reference/addresses.md`, and `test/current-release-target-guard.sh` from the `HANDOFF:*` logs. Set `REVOKE_OLD_BATCHER=1` only after in-flight deploy sessions on the old shell are drained.

Legacy helper-only path (only if shell already exposes `shareMeshHelper()`):

```bash
./script/upgrade-share-mesh-helper.sh
```

### 3. Keeper env (share-mesh completion)

Set on Railway / Vercel keeper surface (values from `deployments/base/v1.16.1-bytecode-manifest.json`):

| Env | Purpose |
|---|---|
| `KEEPER_SHARE_MESH_ENABLED` | `true` (default unless explicitly `false`) |
| `KEEPER_SHARE_MESH_HOOK_REGISTRY_CODE_ID` | `ApprovedV4HooksRegistry` codeId |
| `KEEPER_SHARE_MESH_LP_MANAGER_CODE_ID` | `OVaultLPManager` codeId |
| `KEEPER_SHARE_MESH_DEPLOY_VERSION` | Per-vault CREATE2 version label (default `production`) |
| `KEEPER_SHARE_MESH_REGISTRY_OWNER` | Optional override; defaults to `PROTOCOL_TREASURY` |

Post-graduation keeper order: `sweepCurrency()` → `migrate()` → `deployShareMeshLpManager()` → `seedLpManager()` → `seedRebalance()` → completion invariants → `settledAt`.
