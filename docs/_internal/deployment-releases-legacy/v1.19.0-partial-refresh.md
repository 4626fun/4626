# v1.19.0 partial refresh

## Scope

v1.19.0 is a new per-creator bytecode and CREATE2 namespace on the existing
v1.18.0 Base shared infrastructure. It is not a greenfield infrastructure
redeploy.

Unchanged shared contracts include Registry4626, OVaultFactory4626,
DeploymentBatcher, Phase1/Phase3 helpers, UniversalBytecodeStoreV2,
UniversalCreate2DeployerFromStore, VRFConsumer4626, and SolanaBridgeAdapter.

The bounded mutable changes are:

1. seed and Safe-approve all v1.19 deploy-consumed codeIds;
2. deploy a replacement Phase2 module with immutable LotteryManager4626
   `0xB68F359e01626Ec5d15C624037311C70DacAba43`;
3. atomically approve that module's runtime codehash and rotate the live batcher;
4. synchronize SolanaBridgeAdapter to the same LotteryManager;
5. set `VITE_DEPLOYMENT_VERSION=v1.19.0` for new launches.

AKITA remains on its grandfathered vault stack. Its canary change is limited to
the gauge LotteryManager pointer and a deliberately bounded jackpot reserve.
