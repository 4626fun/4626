## Why greenfield (not another reseal)

Live stack today is **v1.19.3 deploy-bytecode** on **v1.19.1 greenfield infra** with **v1.19.4 Creator-core / Phase1Module** repair. Repo Solidity is ahead of the sealed store (e.g. #757 ODA P0s). Operator decision: ship a **new** Registry / Batcher / Store / CREATE2 / LM stack under `v1.20.0` with **no** legacy launch lane.

A v1.20.0 greenfield gives:

- Fresh `Registry4626`, `LotteryManager4626`, `VRFConsumer4626`, bytecode store, CREATE2 deployer, and batcher shell in one epoch tag
- Correct `PROTOCOL_AUTOMATION_SAFE` immutables from deploy scripts
- Fresh `LotteryAmoeRouter` wired to the new manager (do not reuse prior router — roots are one-shot)
- New hardened `VaultAuxiliaryDeployBatcher` pinned to the **new** store/create2/batcher
- Single product pin: `CURRENT_RELEASE` / `VITE_DEPLOYMENT_VERSION` = `v1.20.0` only

## Custody model (who signs what)

| Step | Signer | Notes |
|------|--------|-------|
| CREATE / CREATE2 broadcast | Admin EOA (`PRIVATE_KEY` → `0xB05Cf0…`) | `forge script --broadcast`; owns registry/manager/router after `DeployInfrastructure` |
| Batcher wiring (`wireDeploymentHelpers`, `setPhase1Module`, Solana/OVault config) | **Protocol treasury Safe** (`0x7d429e…`) via `_safeExec` | Cold custody lane — **not** the forge deployer. Deployer is a Safe owner (threshold 1). |
| Phase 3 Charm `manager` / Ajna `admin` immutables | **Protocol automation Safe** (`0x08f0875…`) | Set in deploy env — **never** treasury |
| AMOE allowlist/ledger publisher | Protocol CSW (`0x793c…`) | Set on router post-deploy |

Do **not** attempt to make the cold treasury Safe the forge `msg.sender` for CREATE2 deploys — scripts are built for EOA broadcast + Safe wiring.

1. `DeployInfrastructure.s.sol` → registry, factory, activation batcher, lottery manager, VRF
2. `deploy-infra-v2.sh` → bytecode store, CREATE2 deployer, vault modules, batcher shell + helpers (epoch `v1.20.0-greenfield`)
3. Regenerates `deployments/base/v1.20.0-bytecode-manifest.json` + frontend deploy bytecode
4. Seeds the **new** `UNIVERSAL_BYTECODE_STORE`

Capture all `HANDOFF:*` lines into `tmp/base-v1.20.0-handoff.env`.

Required post-deploy wiring:

- Treasury Safe: `wireDeploymentHelpers`, `setPhase1Module`, optional `setSolanaConfig` / `setOVaultRuntimeConfig`
- Registry: `setLotteryManager(8453, <new manager>)` if not auto-wired
- Create2 deployer: authorize new batcher
