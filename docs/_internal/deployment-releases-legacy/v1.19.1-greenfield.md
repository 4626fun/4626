# v1.19.1 Greenfield Release (Full Infra Epoch)

Status: **on-chain cutover complete — Creator + Agent canaries outstanding**

Chain: Base mainnet (`8453`)

Release type: **full greenfield** (new shared/global + new phased deploy infra). This is **not** a bytecode-epoch-only refresh and **not** an aux-only rotation.

Authoritative address doc after cutover: `docs/reference/addresses.md`

Orchestrator: `./script/run-greenfield-cutover.sh v1.19.1`

## Why greenfield (not another shell hot-swap)

v1.19.0/v1.19.1 bytecode-epoch work reused the live v1.18.0 shared stack (`Registry4626` `0xDb8570…`, batcher `0x02D7…`, store `0xfa3e…`). A v1.19.1 greenfield gives:

- Fresh `Registry4626`, `LotteryManager4626`, `VRFConsumer4626`, bytecode store, CREATE2 deployer, and batcher shell in one epoch tag
- Correct `PROTOCOL_AUTOMATION_SAFE` immutables from deploy scripts
- Fresh `LotteryAmoeRouter` v3 deployed + wired to the new manager
- New hardened `VaultAuxiliaryDeployBatcher` pinned to the **new** store/create2/batcher (prior aux `0xde93…` stays on the deprecated stack)
- Clean deprecation boundary for the v1.18.0 address table in `docs/reference/addresses.md`

## Custody model (who signs what)

| Step | Signer | Notes |
|------|--------|-------|
| CREATE / CREATE2 broadcast | Admin EOA (`PRIVATE_KEY` → `0xB05Cf0…`) | `forge script --broadcast`; owns registry/manager/router after `DeployInfrastructure` |
| Batcher wiring (`wireDeploymentHelpers`, `setPhase1Module`, Solana/OVault config) | **Protocol treasury Safe** (`0x7d429e…`) via `_safeExec` | Cold custody lane — **not** the forge deployer |
| Phase 3 Charm `manager` / Ajna `admin` immutables | **Protocol automation Safe** (`0x08f0875…`) | Set in deploy env — **never** treasury |
| AMOE allowlist/ledger publisher | Protocol CSW (`0x793c…`) | Set on router post-deploy |

Do **not** attempt to make the cold treasury Safe the forge `msg.sender` for CREATE2 deploys — scripts are built for EOA broadcast + Safe wiring.

## Phase 1 — Broadcast greenfield infra

```bash
set -a && source .env && set +a
export DEPLOYMENT_EPOCH_TAG=v1.19.1
export BASE_FULL_RELEASE_SKIP_VANITY=1
unset UNIVERSAL_BYTECODE_STORE UNIVERSAL_CREATE2_DEPLOYER UNIVERSAL_CREATE2_FROM_STORE \
  DEPLOYMENT_BATCHER DEPLOYMENT_BATCHER_AUTO_HANDOFF \
  REGISTRY REGISTRY_4626 OVAULT_FACTORY LOTTERY_MANAGER VRF_CONSUMER \
  VAULT_ACTIVATION_BATCHER
./script/run-greenfield-cutover.sh v1.19.1
./script/validate-greenfield-handoff.sh tmp/base-v1.19.1-handoff.env
```

This runs:

1. `DeployInfrastructure.s.sol` → registry, factory, activation batcher, lottery manager, VRF, Solana adapter (if still in path)
2. `deploy-infra-v2.sh` → bytecode store, CREATE2 deployer, vault modules, batcher shell + helpers (epoch `v1.19.1-greenfield`)
3. Regenerates `deployments/base/v1.19.1-bytecode-manifest.json` + frontend deploy bytecode
4. Seeds the **new** `UNIVERSAL_BYTECODE_STORE`

Capture all `HANDOFF:*` lines into `tmp/base-v1.19.1-handoff.env`.

Required post-deploy wiring:

- Treasury Safe: `wireDeploymentHelpers`, `setPhase1Module`, optional `setSolanaConfig` / `setOVaultRuntimeConfig`
- Registry: `setLotteryManager(8453, <new manager>)` if not auto-wired
- Create2 deployer: authorize new batcher
