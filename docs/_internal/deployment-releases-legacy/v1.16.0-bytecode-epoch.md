## On-chain operator steps

### 1. Re-seed bytecode store (idempotent)

Store owner signer (protocol treasury Safe owner or delegated EOA):

```bash
export UNIVERSAL_BYTECODE_STORE=0x7D1029a832E2BEd2C961bC912b623b763862Ad3C
export BASE_RPC_URL=<paid Base RPC>
export PRIVATE_KEY=<store owner signer>

# Full pass (may hit gas/RPC limits — use batched runs if needed)
./script/seed-v1160-bytecode-store.sh
```

Batched alternative:

```bash
SEED_OFFSET=0  SEED_LIMIT=12 ./script/seed-v1160-bytecode-store.sh
SEED_OFFSET=12 SEED_LIMIT=12 ./script/seed-v1160-bytecode-store.sh
SEED_OFFSET=24 SEED_LIMIT=12 ./script/seed-v1160-bytecode-store.sh
SEED_OFFSET=36 SEED_LIMIT=12 ./script/seed-v1160-bytecode-store.sh
```

The seed script skips entries whose `codeId` is already present (`pointers(codeId) != 0`). **Changed bytecode requires a new `codeId`** — old entries remain in the store but are no longer referenced by v1.16.0 deploy sessions.

Low-level entry point (same script):

```bash
forge script script/SeedUniversalBytecodeStore.s.sol:SeedUniversalBytecodeStore \
  --rpc-url "$BASE_RPC_URL" --broadcast
```
