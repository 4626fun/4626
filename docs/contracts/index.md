# Smart Contracts

> **Audience:** Protocol engineers, auditors, and integrators working directly with 4626 smart contracts.

This section documents the public-facing smart contracts that power the 4626 protocol.

It covers:
- Core vault contracts
- Keeper automation
- Lottery mechanics
- Deployment patterns (CREATE2)

Source code lives in `/contracts`.

This documentation is curated and may omit internal helpers, tests, or deployment-only contracts.
