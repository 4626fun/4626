# ve■4626 (`ve4626`)

Vote-escrow **commitment**: lock **■4626 only** for dual-decay power.

Canonical naming: [ve-naming.md](./ve-naming.md).

| | |
|--|--|
| **Product** | **ve■4626** |
| **Contract** | `ve4626` |
| **Lock asset** | **■4626 only** (`wrappedShareOFT` immutable) — not creator ShareOFT |
| **Utilities** | `ve4626Utility` → **veVote** / **veChance** |

## Purpose

- Lock **■4626** (protocol ShareOFT / $4626 stack) → dual-decay power
- **Not** creator ■ (e.g. ■AKITA) or Creator Coin — `lock` reverts `InvalidToken`
- Claim **vote** / **chance** via `ve4626Utility` (not automatic)
- Gauge voting + fees use **veVote** when wired
- Lottery mult uses **veChance** when wired (opt-in)
- After decay, `sync` keeps utilities ≤ capacity

## Lock API

```solidity
// token MUST be wrappedShareOFT (■4626)
lock(token, amount, duration);
extendLock(newEnd);
increaseLock(amount);  // same asset only
unlock();
getVotingPower(user);
getTotalVotingPower(); // dual-decay total — use this for share math
```

## Utility API

```solidity
// ve4626Utility
claimVote(amount);
claimChance(amount);      // opt-in lottery edge
claimAllOutstanding();    // default: vote only
forfeitVote / forfeitChance / forfeitAll();
sync(user);               // burn excess after dual-decay (chance first)
previewUtilities(user);   // view: post-haircut vote/chance
effectiveVoteOf(user);    // decay-safe gauge weight
effectiveChanceOf(user);  // decay-safe boost share
// Prefer effective* over raw voteOf/chanceOf (may be stale until sync)
```

## Consumer wiring (deploy)

```solidity

```

```text

working = min(l, lim)                         // Curve: cap at l, not 2.5·l
quotedBoost = working/(0.4·l) ∈ [1.0, 2.5]  // BPS 10_000–25_000 to LM
odds    = baseWinChance × quotedBoost / 10_000

l  = min(creatorShareUSD, swapUSD)
L  = total creator ShareOFT supply USD
ve = effectiveChanceOf (veChance)
```

| | quotedBoost BPS | vs size-based base |
|--|----------------:|-------------------:|
| No veChance (has Share) | 10_000 | **1.0×** (neutral) |
| ve share ≥ LP share | 25_000 | **2.5×** |
| No Share (`l=0`) | personal off | base unchanged |
