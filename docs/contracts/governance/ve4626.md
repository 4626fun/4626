# ve4626

The ve4626 contract implements vote-escrowed tokenomics where users lock ■TOKEN or ▢TOKEN to receive voting power that decays linearly over time.

---

## Overview

| Property | Value |
|----------|-------|
| Inheritance | ERC721 (NFT position) |
| State | Lock records, voting power |
| Token types | ■TOKEN, ▢TOKEN |

---

## Locking mechanism

### Create lock

```solidity
function lock(
    address token,
    uint256 amount,
    uint256 duration
) external returns (uint256 tokenId);
```

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| token | address | ■TOKEN or ▢TOKEN address |
| amount | uint256 | Amount to lock |
| duration | uint256 | Lock duration in seconds |

**Returns:** NFT token ID representing the lock position.

**Example:**

```solidity
// Lock 1000 ■AKITA for 2 years
ve4626.lock(shareOFT, 1000e18, 730 days);
```

### Lock parameters

| Parameter | Value |
|-----------|-------|
| Minimum lock | 7 days |
| Maximum lock | 4 years (1460 days) |
| Minimum amount | 1 token |

## Voting power

### Calculation

Voting power decays linearly from initial amount to zero:

```solidity
function getVotingPower(uint256 tokenId) public view returns (uint256) {
    Lock memory lock = locks[tokenId];
    
    if (block.timestamp >= lock.end) return 0;
    
    uint256 timeRemaining = lock.end - block.timestamp;
    return (lock.amount * timeRemaining) / MAX_LOCK_DURATION;
}
```

### Decay curve

```
Voting Power
    │
1000│■
    │  ■
 750│    ■
    │      ■
 500│        ■
    │          ■
 250│            ■
    │              ■
   0│________________■___
    0   1   2   3   4  Years
```

### Example

Lock 1000 tokens for 4 years:

| Time | Remaining | Voting power |
|------|-----------|--------------|
| Day 1 | 4 years | 1000 |
| Year 1 | 3 years | 750 |
| Year 2 | 2 years | 500 |
| Year 3 | 1 year | 250 |
| Year 4 | 0 | 0 |

## Lock management

### Increase amount

```solidity
function increaseAmount(uint256 tokenId, uint256 amount) external;
```

Add more tokens to an existing lock without changing duration.

### Increase duration

```solidity
function increaseUnlockTime(uint256 tokenId, uint256 newEnd) external;
```

Extend lock duration. Can only extend, not reduce.

### Withdraw

```solidity
function withdraw(uint256 tokenId) external;
```

Withdraw tokens after lock expires. Reverts if lock is still active.

### Early exit (with penalty)

```solidity
function earlyExit(uint256 tokenId) external;
```

Exit before lock expires with a penalty. Penalty is proportional to remaining lock time.

## Position NFT

### ERC721 representation

Each lock is an NFT that can be transferred or traded:

```solidity
// Transfer lock position
ve4626.transferFrom(owner, newOwner, tokenId);

// Check owner
address owner = ve4626.ownerOf(tokenId);

// Get user's positions
uint256[] memory positions = ve4626.getPositions(user);
```

### Metadata

```solidity
function tokenURI(uint256 tokenId) external view returns (string memory);
```

Returns JSON metadata including:
- Lock amount
- Lock end time
- Current voting power
- Token type (■ or ▢)

## Delegation

### Delegate votes

```solidity
function delegate(address delegatee) external;
```

Delegate all voting power to another address. Delegatee can vote on your behalf.

### Self-delegation

By default, users must self-delegate to vote:

```solidity
// Enable voting for yourself
ve4626.delegate(msg.sender);
```

### Query delegation

```solidity
function delegates(address account) external view returns (address);
function getVotes(address account) external view returns (uint256);
```

## Checkpointing

### Historical balances

The contract maintains checkpoints for historical voting power:

```solidity
function getPastVotes(address account, uint256 timestamp) 
    external view returns (uint256);

function getPastTotalSupply(uint256 timestamp) 
    external view returns (uint256);
```

Used for governance proposals and reward calculations.

## Integration

### For UI developers

```solidity
// User's total voting power
uint256 power = ve4626.getVotes(user);

// User's lock positions
uint256[] memory tokenIds = ve4626.getPositions(user);

// Single position details
Lock memory lock = ve4626.locks(tokenId);
uint256 votingPower = ve4626.getVotingPower(tokenId);

// Time until unlock
uint256 timeRemaining = lock.end > block.timestamp 
    ? lock.end - block.timestamp 
    : 0;
```

### For governance

```solidity
// Snapshot voting power for proposal
uint256 proposalTime = block.timestamp;

// Later, check historical power
uint256 voterPower = ve4626.getPastVotes(voter, proposalTime);
```

## Security

### Reentrancy protection

All state-changing functions use reentrancy guards:

```solidity
modifier nonReentrant() {
    require(!_locked, "ReentrancyGuard: reentrant call");
    _locked = true;
    _;
    _locked = false;
}
```

### Access control

| Function | Access |
|----------|--------|
| lock | Public |
| increaseAmount | Position owner |
| increaseUnlockTime | Position owner |
| withdraw | Position owner (after expiry) |
| earlyExit | Position owner |
| delegate | Public |
