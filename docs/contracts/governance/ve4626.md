# ve4626

Vote-escrow token for governance participation and lottery boosts.

## Purpose

ve4626 enables users to:
- Lock tokens for voting power
- Earn personal lottery boosts (up to 2.5x)
- Participate in gauge voting
- Earn voter rewards (9.61% of fees)

## Key Functions

### Locking

```solidity
// Lock tokens for voting power
function lock(uint256 amount, uint256 duration) external;

// Extend lock duration
function extendLock(uint256 newDuration) external;

// Increase locked amount
function increaseLock(uint256 additionalAmount) external;

// Unlock after lock period
function unlock() external;
```

### View Functions

```solidity
// Get voting power at current time
function balanceOf(address account) external view returns (uint256);

// Get total voting power
function totalSupply() external view returns (uint256);

// Get lock info
function locked(address account) external view returns (uint256 amount, uint256 end);
```

## Boost Mechanics

Lock duration affects boost:

| Lock Duration | Max Boost |
|---------------|-----------|
| 1 week | 1.0x |
| 1 month | 1.25x |
| 6 months | 1.75x |
| 1 year | 2.0x |
| 4 years | 2.5x (max) |

## Integration with Lottery

The `ve4626BoostManager` calculates boosts:

```solidity
// Get personal boost for lottery
function calculateBoost(address user) external view returns (uint256 boostBps);

// Get total probability boost
function getTotalProbabilityBoost(address user) external view returns (uint256 boostBps);

// Check if user has any boost
function hasBoost(address user) external view returns (bool);
```
