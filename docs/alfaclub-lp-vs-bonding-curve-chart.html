AlfaClub Bonding Curve vs Creator Coin LP

The primary curve prices keys from total ERC1155 supply. The secondary LP prices keys from ERC20 and key reserves. This chart normalizes the ERC20 side to USDC so the shapes can be compared directly. Defaults are set to AlfaClub room #1043: Social / Casual with 73 keys minted.

Primary buy: sum(i^2) * priceUnit / divisor + fees
LP buy: x * q / (y - q), then grossed up by 6.9%
LP sell: x * q / (y + q), then reduced by 6.9%

Parameters

The LP is auto-seeded at the midpoint of the one-key no-arbitrage range when that range exists. Otherwise it uses the midpoint of the primary one-key bid and ask.
