## Browse

The sidebar groups ~70 root runbooks into lanes. Subfolders (`deployment/`, `automation/`, `services/`, `kpr/`, `agent-runtime/`) autogenerate from the repo. Use search (⌘K) for one-off lookup.

Runbooks tagged `status: historical` are kept for audit context — do not treat them as current production procedure.
