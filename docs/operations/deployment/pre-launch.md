# Pre-Launch Checklist

Complete these steps before launching.

## Token Preparation

- [ ] Creator Coin deployed and verified
- [ ] 50M+ tokens available for initial deposit
- [ ] Token metadata configured (name, symbol, decimals)

## Wallet Setup

- [ ] Smart Wallet created (Coinbase recommended)
- [ ] Sufficient ETH for gas (if not using paymaster)
- [ ] Wallet connected to Base network

## Contract Configuration

- [ ] Vault parameters decided (name, symbol)
- [ ] OFT parameters decided (name, symbol)
- [ ] Fee recipient addresses confirmed

## Post-Deployment

- [ ] Verify all contracts on BaseScan
- [ ] Configure DEX pools as SwapOnly
- [ ] Test deposit/withdraw flow
- [ ] Test lottery entry creation
