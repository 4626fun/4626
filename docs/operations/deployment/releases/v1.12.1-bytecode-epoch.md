# v1.12.1 Bytecode Epoch (Module v2 + Burn-Stream Queuer Bridge)

Status: **operator cutover** — align `CreatorOVault` deploy bytecode with live `.v2` modules, re-seed store, optionally rotate Phase 1 module when admin module changes.

Date: 2026-05-28  
Chain: Base mainnet (`8453`)

`v1.12.1` supersedes `v1.12.0` by:

| Change | Detail |
|---|---|
| `CreatorOVault` fingerprint | `CreatorOVaultModuleStorage.v2` (matches wired core/strategies/admin modules) |
| Admin module | `setBurnStreamAuthorizedQueuer(address,bool)` bridge for PayoutRouter → burn stream |
| Treasury automation | Server-side `PayoutRouter.setKeeper` / `setSwapPath` / external approvals via protocol treasury Safe |
| Keeper fan-out | `keeper_jobs` `payout` / `payout-router` workflow → harvest + optional burn-stream `checkpoint()` |

- `DeploymentBatcher` shell `0xa99058f424FB3ACC639F59355C65C40149030651`
- `UniversalBytecodeStoreV2` `0x8B51E6784A0C6681F5de25bAC4f9B2fDCEDE72b4`

## On-chain operator steps

### 1. Seed bytecode store (chunked)

```bash
export UNIVERSAL_BYTECODE_STORE=0x8B51E6784A0C6681F5de25bAC4f9B2fDCEDE72b4
export BASE_RPC_URL=<paid Base RPC>
export PRIVATE_KEY=<protocol treasury signer>

forge script script/SeedUniversalBytecodeStore.s.sol:SeedUniversalBytecodeStore \
  --rpc-url "$BASE_RPC_URL" --broadcast
```

Use `SEED_OFFSET` / `SEED_LIMIT` for batched runs if gas limits bite.

### 3. PayoutRouter treasury wiring (post phase-2)

Dry-run plan:

```bash
pnpm -C frontend exec tsx scripts/ops/payout-router-setup-safe.ts \
  --router 0x<PayoutRouter> --creator 0x<CreatorCoin>
```

Execute (protocol treasury Safe owner key in env):

```bash
pnpm -C frontend exec tsx scripts/ops/payout-router-setup-safe.ts \
  --router 0x<PayoutRouter> --creator 0x<CreatorCoin> --execute
```

Or enable deploy-session auto hook on Vercel:

```bash
PAYOUT_ROUTER_TREASURY_AUTO_SETUP=1
```

HTTP (machine auth): `POST /api/keeper/payout-router-treasury-setup` with `{ payoutRouterAddress, creatorTokenAddress, execute: true }`.

### 4. Keeper jobs payout fan-out

Production Vercel:

```bash
KEEPER_ACTIVE_VAULT_ENQUEUE_ENABLED=1
KEEPER_ACTIVE_VAULT_WORKFLOWS=sweep,tend,report,rebalance,payout
KEEPER_ACTIVE_VAULT_PAYOUT_RECIPIENT_MODE=payout_router
PAYOUT_ROUTER_KEEPER=<keeper EOA or CSW>
KPR_PRIVATE_KEY=<matching signer>
```

Cron `/api/keeper/jobs/enqueue-active-vaults` enqueues `POST /api/keeper/payout-router-harvest` per vault (dedupe `active-payout:{vault}`).
