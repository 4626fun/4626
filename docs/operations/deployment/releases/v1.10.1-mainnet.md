# v1.10.1 Mainnet Release Packet

Canonical release packet for the planned `v1.10.1` Base mainnet redeploy.

> **Pre-broadcast skeleton.** This document intentionally contains placeholders
> until the broadcast completes and the post-broadcast evidence pass fills in
> addresses, transaction hashes, verification outputs, and final operational
> notes.

Release target: `v1.10.1`  
Chain: Base mainnet (`8453`)  
Runbook: `docs/operations/deployment/v1.10.1/deployment-instructions.md`

## Version Note

`v1.10.1` is the clean restart of the abandoned `v1.10.0` redeploy packet.
Future new minor lines should still start at `vX.Y.0`; this packet uses
`v1.10.1` so the restarted release cannot be confused with the earlier
uncompleted attempt. See `docs/operations/deployment/releases/index.md` for
the convention note.
