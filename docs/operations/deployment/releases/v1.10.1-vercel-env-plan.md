v1.10.1 broadcast completes and the replacement contract addresses are
known.

## Step 14 operator commands

Run only after the v1.10.1 broadcast has produced the canonical router address.
Run the `vercel env rm` / `vercel env add` replacement only if post-broadcast
operator verification confirms the production value matches one of the 6 orphan
router addresses. If it does not match, skip the rm/add and record the
verification outcome in broadcast evidence.

```bash
# Verify current value locally without committing or sharing secrets.
vercel env pull /tmp/.env.production --environment production --cwd frontend

# If LOTTERY_AMOE_ROUTER points at one of the v1.10.1 orphan router addresses,
# replace it with the freshly broadcast v1.10.1 router address.
vercel env rm LOTTERY_AMOE_ROUTER production --cwd frontend
printf '%s\n' '<v1.10.1 router TBD post-broadcast>' | vercel env add LOTTERY_AMOE_ROUTER production --cwd frontend

# Remove the local decrypted env file after verification.
rm /tmp/.env.production
```
