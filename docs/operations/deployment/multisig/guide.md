# Multisig Operations

Using Safe multisig for 4626 operations.

## Setup

1. Create Safe on [safe.global](https://safe.global)
2. Add required signers
3. Set threshold (e.g., 2/3)

## Executing Transactions

1. Create transaction in Safe UI
2. Collect signatures
3. Execute once threshold met

## Recommended Configuration

| Parameter | Recommendation |
|-----------|----------------|
| Signers | 3-5 trusted parties |
| Threshold | 2/3 or 3/5 |
| Owner | Safe address |
