# Security Policy

Thank you for helping keep **4626** secure.

4626 combines smart contracts, cross-chain messaging, wallet/account-abstraction flows, and a frontend/API surface. Please report suspected vulnerabilities **privately** and do **not** open public GitHub issues for security matters.

## How to Report

Email **hello@4626.fun** with the subject line:

`[SECURITY] short description`

For issues that put live users or funds at immediate risk, use:

`[CRITICAL] short description`

You may also report via GitHub Private Vulnerability Reporting (Security Advisories) for this repository.
For machine-readable contact discovery, see `https://4626.fun/.well-known/security.txt`.

Please include a clear summary, affected components, reproduction steps, and estimated impact. Do not test in a way that puts real user funds or production availability at risk.
